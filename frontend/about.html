資料政策

資料來源與可信度

PartsHub 是公開資料整理與初步查詢平台，不是原廠 EPC、VIN build sheet 或即時庫存服務。

驗證狀態

每筆適配資料會區分 confirmed、likely、conditional、incompatible、unknown。未驗證或 demo 資料不代表保證適用。

購買前確認

請核對 VIN、生產日期、引擎碼、變速箱、選配代碼及原車料號。煞車、氣囊、燃油、高壓電與其他安全關鍵零件應由專業技師安裝。

圖片與來源

目前圖片以來源 URL 為主，不代表取得原廠爆炸圖再發布權。若發現來源或適配錯誤，請透過網站管理者提出更正。

VIN 隱私

前台不顯示完整 VIN；目前 VIN API 僅做格式驗證與遮蔽回傳，尚未連接授權解碼供應商。
